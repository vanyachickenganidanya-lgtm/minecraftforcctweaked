# Minecraft 3D для CC:Tweaked

Программный 3D воксельный движок, стилизованный под Minecraft, работающий на
**ComputerCraft: Tweaked** через **Advanced Monitor**. Рендеринг —
полностью софтварный, в ASCII-символах, с z-буфером, освещением по
нормали и aggressive оптимизациями.

## Возможности

* 3D-мир 16×32×16 чанки, процедурная генерация (3D-шум)
* 5 типов блоков: трава, камень, песок, вода, воздух
* Greedy meshing — склейка смежных граней в плоскости (в разы меньше
  треугольников)
* Z-буфер — корректное перекрытие объектов
* Back-face culling — отсечение обратных граней
* Frustum culling — отсечение чанков за пределами пирамиды видимости
* Distance culling + LOD — дальние чанки пропускаются или упрощаются
* Адаптивный FPS — при просадке движок сам снижает детализацию
* Кэш сеток чанков — повторно сгенерированные области не пересчитываются
* Управление: WASD, Space, стрелки или мышь
* **Установщик** с выбором пути установки и параметров
* Стартовый конфиг-файл + опциональный `startup`-автозапуск

## Требования

* Minecraft 1.20.1+ с модом **CC: Tweaked** (≥ 1.101.0)
* **Advanced Monitor** (обычный монитор не подойдёт — нужна поддержка
  цветов и масштабирования)
* Компьютер (любой уровень)

## Установка

1. Скопируйте папку проекта (`installer.lua`, `minecraft3d.lua`, `src/`)
   в корень диска компьютера (`/`) любым способом (pastebin put, дискета
   с `wget`, флешка и т.д.).
2. Поставьте **Advanced Monitor** рядом с компьютером.
3. В терминале компьютера:
   ```
   installer
   ```
4. Выберите пункт «1) Установить», укажите путь
   (по умолчанию `/minecraft3d`), настройте параметры.
5. После установки:
   ```
   /minecraft3d/minecraft3d
   ```
   или, если выбрали автозапуск — игра запустится сама при старте.

## Структура проекта

```
installer.lua         # установщик с выбором пути и настроек
minecraft3d.lua       # точка входа
src/math3d.lua        # матрицы 4×4, проекция, lookAt
src/framebuffer.lua   # софт-Z-буфер + ASCII-кадр
src/raster.lua        # растеризатор треугольников + освещение
src/noise.lua         # 3D value-noise (4 октавы)
src/world.lua         # чанки, генерация мира, greedy meshing
src/optimizer.lua     # frustum/distance culling, адаптивный FPS
src/renderer.lua      # MVP, проекция граней, пайплайн
src/game.lua          # игровой цикл, ввод, физика
```

## Производительность

Узкое место — растеризатор треугольников: один кадр 80×30 = 2400 пикселей,
и каждый треугольник проходит по барицентрической формуле по всем
покрытым пикселям. Поэтому:

* Чем меньше монитор — тем выше FPS. Используйте `setTextScale(0.5)` —
  это даёт 4× больше пикселей, но и нагрузка ×4.
* Снижайте `chunkDist` (радиус загрузки) и `skipDistance` (дальность
  отрисовки) для слабых машин.
* На обычном компьютере без модов на производительность можно ожидать
  10–20 FPS в мире радиуса 3 чанка.

## Управление в игре

| Клавиша | Действие |
|---|---|
| W / S | вперёд / назад |
| A / D | стрейф влево / вправо |
| Space | прыжок |
| ← / → | поворот камеры (yaw) |
| ↑ / ↓ | наклон камеры (pitch) |
| мышь (если есть) | обзор |
| Q / Esc | выход |
